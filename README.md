# Health Tracker

A full-stack web application for tracking basic health information, featuring BMI calculation and a user-focused interface for managing health-related data.

## Overview

Health Tracker was developed as a practical full-stack project to apply modern web development concepts across the frontend, backend, database, and deployment layers.

The application uses React.js for the frontend and Node.js with Express.js for backend services, with MongoDB providing persistent data storage.

## Features

- BMI calculation and tracking
- Health-related data management
- User-focused interface
- REST API-based frontend/backend communication
- Persistent data storage
- Separate frontend and backend architecture
- Deployed full-stack application

## Architecture

The project is organized into independent frontend and backend components.

```text
Health Tracker
├── Frontend
│   └── React.js
│
├── Backend
│   ├── Node.js
│   └── Express.js
│
└── Database
    └── MongoDB

The frontend communicates with the backend through REST APIs. The backend handles application logic and database operations, while MongoDB provides persistent storage for application data.
